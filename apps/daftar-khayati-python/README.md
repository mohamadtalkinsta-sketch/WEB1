# دفتر خیاطی اندروید، نسخهٔ مستقل Python

این پروژه یک اپ اندرویدی بومی با Python و Kivy است. رابط اصلی با ویجت‌های Kivy ساخته می‌شود؛ WebView، صفحهٔ HTML، سایت یا سرویس اینترنتی در اجرای برنامه وجود ندارد.

## امکانات نسخهٔ اولیه
- داشبورد دستمزد امروز، تعداد کار، مجموع دریافتی و ماندهٔ حساب
- تعریف و ویرایش کارت لباس/قطعه برای کار تکمیلی و زنجیره‌ای
- ثبت روزانهٔ تعداد، دستمزد، تاریخ، رنگ، سایز، دکمه و هزینه‌های بیرونی
- محاسبهٔ خودکار دستمزد خالص
- ثبت دریافتی جدا از دستمزد و گزارش مانده
- ذخیرهٔ محلی در JSON داخل فضای خصوصی برنامه
- جست‌وجوی کارت‌ها و فیلتر نوع کار

## ساخت APK
با تغییر شاخهٔ ساخت، GitHub Actions تست‌های Python را اجرا می‌کند و سپس با Buildozer و python-for-android فایل APK را می‌سازد. خروجی در Artifact با نام `daftar-khayati-python-native-apk` قرار می‌گیرد.

## محدودیت‌های فعلی
این نسخهٔ اولیه داده‌ها را روی همان دستگاه نگه می‌دارد و همگام‌سازی ابری ندارد. پشتیبان JSON فعلاً در فضای خصوصی اپ ایجاد می‌شود و برای انتقال مستقیم به پوشهٔ Downloads/اشتراک‌گذاری باید رابط ذخیره/اشتراک‌گذاری Android افزوده شود. تصاویر کارت در این نسخه از نمادهای بومی استفاده می‌کنند و به دانلود آنلاین وابسته نیستند.
