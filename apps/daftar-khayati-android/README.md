# دفتر خیاطی برای اندروید

این پوشه بستهٔ اندرویدی قابل نصب را می‌سازد. رابط کاربری از نشانی عمومی Vercel بارگذاری می‌شود؛ بنابراین اتصال اینترنت برای بازکردن نسخهٔ اولیه و دریافت به‌روزرسانی رابط لازم است. داده‌های واردشده در فضای ذخیره‌سازی WebView همین برنامه نگه‌داری می‌شوند و با مرورگر Chrome یا دستگاه‌های دیگر همگام‌سازی خودکار ندارند.

## عکس لباس
- «عکس گرفتن با دوربین» از طریق انتخاب‌گر اندروید، دوربین را باز می‌کند.
- «انتخاب از گالری» امکان انتخاب عکس موجود را می‌دهد.
- عکس در سمت رابط، کوچک و فشرده می‌شود و در دادهٔ محلی همان دستگاه می‌ماند.

## ساخت APK
Workflow با هر push روی شاخهٔ `build/daftar-khayati-apk` فایل `app-debug.apk` را می‌سازد و به‌صورت artifact در GitHub Actions قرار می‌دهد. این APK برای نصب شخصی است و با امضای debug ساخته می‌شود، نه برای انتشار در فروشگاه.
